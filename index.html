AdMob Daily Report

A private reporting tool maintained by Jeet Patel.

What this tool does

This tool uses Google Apps Script and the Google AdMob API to read the previous day's estimated AdMob Network earnings and send an email summary to a recipient configured by the authorized account operator.

It supports separate authorized setups for multiple AdMob publisher accounts. Each setup accesses only the account permitted by its Google authorization.

Permissions and access

The tool requests permission to read AdMob reports, connect to the AdMob API and send report emails. It does not request permission to read your email inbox or change AdMob settings.

Private use

This website provides information only. Reports and account credentials are not published here. There is no public sign-up. Authorization takes place through Google when the script runs.

This is an independent tool and is not affiliated with or endorsed by Google.
